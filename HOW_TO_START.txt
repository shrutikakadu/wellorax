----------------------------------------------------------------
STEP 2: Start BACKEND (open a new PowerShell window)
  cd backend
  npm run dev

  Backend runs at: http://localhost:3001

----------------------------------------------------------------
STEP 3: Start FRONTEND (open another PowerShell window)
  cd frontend
  npm run dev

  Frontend runs at: http://localhost:5173
